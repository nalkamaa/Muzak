# Muzak

Ilmaista musiikkia ja nettiradiota laillisista avoimista lähteistä. Ei mainoksia, ei kirjautumista.

- **Radiokanavat:** Suomi, Pop, Rock, Metalli, Jazz, Blues, Elektroninen, Klassinen ja Joulu. Asemat tulevat avoimesta [Radio Browser](https://www.radio-browser.info/) -hakemistosta.
- **Konsertit:** keikkatallenteita [Internet Archiven Live Music Archivesta](https://archive.org/details/etree), esittäjälista A–Ö.
- **Suosikit** tallentuvat selaimeen.
- Hengelliset ja uskonnolliset kanavat sekä puhekanavat ja venäläiset asemat suodatetaan pois. Http-streamit piilotetaan, koska ne eivät soi https-sivulla.

Toimii selaimessa puhelimella ja tietokoneella. Puhelimessa: avaa sivu ja valitse "Lisää kotinäyttöön".

Julkaisu: GitHub Pages, haara `main`, kansio `/`.
